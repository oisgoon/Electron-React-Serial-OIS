# 🔌 Electron-React-Serial-OIS

**Electron-React-Serial-OIS**는 시리얼 통신을 통해 외부 장치와 데이터를 주고받고, 그 로그를 실시간으로 모니터링하는 데스크탑 애플리케이션입니다.  
React 기반 UI와 Electron을 통해 크로스 플랫폼에서 동작하며, 직관적인 시리얼 통신 기능을 제공합니다.

## 📦 기술 스택

- **Electron** – 데스크탑 애플리케이션 프레임워크
- **React** – 사용자 인터페이스 프론트엔드 라이브러리
- **TypeScript** – 정적 타입을 지원하는 자바스크립트
- **Node.js** – 백엔드 런타임 환경
- **SCSS** – 스타일링 언어

---

## ⚙️ 주요 기능

- 시리얼 포트 연결 및 선택
- 시리얼 데이터 송수신 기능
- 수신된 데이터 로그 모니터링

---

## 📥 설치 방법

```bash
git clone https://github.com/oisgoon/Electron-React-Serial-OIS.git
cd Electron-React-Serial-OIS
npm install
```

## 추후 개선사항
- 빠른 속도로 전송될 경우 버벅이고 프로그램이 다운됨
- 많은 데이터를 받을 경우에도 버벅이고 프로그램이 다운됨
